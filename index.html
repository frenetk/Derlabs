⚙️ Backend (Netlify Functions)

Las funciones ya están incluidas en este mismo sitio, en /.netlify/functions — no necesitas configurar nada acá salvo que uses otro hosting.

El token se usa solo desde las Netlify Functions del backend — nunca se expone a los clientes. El código de las funciones está en netlify/functions/.

⚠️ Intentos de pago sin confirmar

Cada vez que alguien inicia un pago con MercadoPago, se guarda un registro acá antes de que se cree el pedido. Si todo funciona bien, este registro se marca "confirmado" apenas el pedido se crea, y no necesitas hacer nada. Si algo falla del lado del webhook (poco común, pero puede pasar), el registro queda en "iniciado" o "error" aunque el cliente sí haya pagado — revisa acá si un cliente dice haber pagado pero no ves su pedido.

📧 Emails transaccionales

Paso 1: Crea una cuenta gratis en resend.com
Paso 2: Verifica tu dominio (o usa onboarding@resend.dev para pruebas)
Paso 3: Copia tu API key y pégala abajo

Mientras falte la API key, los emails no se envían (falla silenciosa). Los pedidos se crean igual en Firestore.

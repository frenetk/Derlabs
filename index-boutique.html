Pagos

Mercado Pago

  1. Entra a mercadopago.cl con tu cuenta.
  2. Ve a "Tu negocio" y luego a "Credenciales".
  3. Copia tu Access Token de producción y pégalo aquí.

El token se usa solo en el servidor (Netlify Functions): nunca llega al navegador de tus clientes.

Servidor de pagos

Las funciones ya vienen en este mismo sitio. Solo cámbialo si usas otro hosting.

Pagos sin confirmar

Cada pago con Mercado Pago deja un registro antes de crear el pedido. Si un cliente dice que pagó y no ves su pedido, revísalo aquí.

Correos

Correos automáticos (Resend)

  1. Crea una cuenta gratis en resend.com.
  2. Verifica tu dominio (o usa onboarding@resend.dev para probar).
  3. Copia tu API key y pégala abajo.

Mientras falte la API key, los correos no se envían. Los pedidos se crean igual.
